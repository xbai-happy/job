# Job
博士后研究员-大模型算法
在金融科技的浪潮中，万得作为行业先锋，凭借深厚技术积累和创新精神，始终走在前沿。我们拥有上海市浦东新区政府颁发的博士后实践基地资质，为科研人才搭建广阔平台，提供丰富资源。为推动大模型在金融领域的深度应用，我们向全球诚邀大模型研究方向的博士后候选人。你将依托万得海量金融数据与先进设施开展前沿研究，主导模型架构创新与金融场景应用，与顶尖团队和专家合作，攻克金融风险预测等难题，以科研成果推动行业智能化发展。

岗位职责：
1、负责研究、创新、开发和优化最先进的算法和模型，包括模型架构、LLM大模型预训练方法、高效微调、模型评估及迭代等，提升模型的准确性和性能，并在业务场景中落地；
2、研究自然语言处理、机器学习等方向的前沿技术问题，打造领先技术影响力，方向包括但不限于NLP大模型、对话、问答、文本生成、信息抽取等方向；
3、与产品和业务团队紧密合作，根据业务场景的需求，快速迭代和开发AI应用程序，解决业务上的痛点和挑战，实现卓越的用户体验；
4、过滤客户需求，向自然语言大模型核心算法团队提供有价值的算法优化需求，促进核心模型持续改进；
5、跟踪和研究大模型领域的最新技术动态，参与技术交流与分享，推动团队整体技术水平的提升，提出创新性的研究课题和项目方案。

任职要求：
1、具有相关学科国内外优秀大学博士学位，专业方向是计算机、软件、电子工程、数学、物理、人工智能、统计学等相关方向；
2、深⼊了解⼤语⾔模型的原理、架构和训练⽅法；
3、在人工智能领域内的国际权威期刊/顶会发表过论文，包括NeurIPS、NIPS、ICML、ICLR、ACL、EMNLP、 AAAI、WWW、CVPR、TIP、ICCV、ECCV等相关顶会/期刊；或ACM/Kaggle等知名比赛取得优异成绩者；
4、具备创新研究能力及良好的学习能力，对AI研发及应用落地产业化有强烈热情，对解决挑战性问题充满激情，具有较强的沟通能力和团队协作能力。

工作地点：上海、南京
